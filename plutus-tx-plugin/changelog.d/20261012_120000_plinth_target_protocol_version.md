### Added

- The plugin option `target-protocol-version` (default 11, the major protocol
  version of mainnet). The compiled code has a `case` on a value of a built-in
  type only if the target protocol version permits it: on Bool, unit, pairs,
  lists and Integer from 11, and on `Data` from 12. Before, the data decoders
  generated by `makeIsDataIndexed` had a `case` on `Data`, so the scripts
  failed on chains before protocol version 12.
